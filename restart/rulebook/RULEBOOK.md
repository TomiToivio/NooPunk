# NoöPunk — rulebook (restart, in progress)

**Status:** draft, version 0.1 — **intentionally almost empty.**
**Authority:** Tomi Toivio is the designer. Rules are added here one piece at a time, and each piece
is implemented in the paired Godot game in the same change.

## Premise

NoöPunk is a role-playing game about people who live inside a thinking world: the Noösphere, the
layer of human and machine thought that has become navigable. The premise will grow as the game grows.
Nothing in this file is invented ahead of the design.

## What this rulebook is for

One page of rules per step. A rule exists here only when Tomi has stated it, and only after the same
change made it playable in the Godot project at `restart/game/`. The rulebook describes **what the
game does**; the game **implements** it. Neither invents canon the other does not have.

## How a rule is added

1. Tomi writes one small rule or scenario fragment.
2. It is written into this file, in the section above that it belongs to.
3. The same change implements its observable counterpart in `restart/game/`.
4. Consistency between the two is checked, reviewed and merged.
5. Only the child issue that carried the rule is closed. The meta-issue stays open.

See `restart/START_HERE.md` for the canonical paths and the run instructions.
