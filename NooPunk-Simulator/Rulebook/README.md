# NoöPunk Simulator Rulebook

**Agent-maintained explanatory and game-rule documentation.** This is where AI agents faithfully **summarize, interpret and operationalize** Tomi's drafts in [`../Paper/`](../Paper/) into reviewable, human-readable rules. **Tomi's Paper is read-only to agents**, even to fix formatting.

## Sections to develop incrementally
- Social Graph / SNA: society as an actor and relationship network; optional Castells/Luhmann interpretations explicitly labeled.
- Ideology Graph / DA + DNA: faction ideology, articulation, Formula of Populism, and the actor–concept–position bridge.
- Physical Graph: Helsinki city locations and routes, then nested interior/location graphs.
- Shared Graph/Tag compatibility, examples, versioned rules ↔ Python code mapping and scientific-vs-fiction boundaries.

Start with Social Graph only; document each verified implementation alongside Python and tests. **Do not create a duplicate RPG/CWN rulebook**. Follow [issue #1309](https://github.com/TomiToivio/NooPunk/issues/1309).
