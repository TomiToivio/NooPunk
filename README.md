# Noöpunk

> *The future arrives one generation behind the vision. Keep pedalling.*

**Noöpunk is a homebrew add-on for [Eclipse Phase](https://eclipsephase.com/),
the roleplaying game of transhuman survival by Posthuman Studios.**

This repository is under construction. The full setting material —
Tommy Pilgrim's book, the campaign frameworks, the Mandela editions —
will be rebuilt here as Eclipse Phase-compatible content.
