## Original prompt (verbatim text, Markdown formatting normalized)

Add this issue: [https://github.com/TomiToivio/NooPunk](https://github.com/TomiToivio/NooPunk)

Agents should only log my longer prompts that contain a lot of text about background or rules that can be useful in the future. They should not log shorter prompts like "do this" or "fix this" or "what is the best NoöPunk movie" etc.

Agents should use this guideline: Don't log my shorter prompts. Always log my longer prompts since they have many ideas that should be saved for possible recycling of abandoned ideas. Do this only for my long NoöPunk design and development prompts. I should do this myself but I will probably forget it.

Save my prompts in directory Prompts. No need to categorize them by subproject because they overlap so much.

Do this only when my prompt is clearly related to one of the NoöPunk subprojects, contains ideas, rules, design or theory, contains a lot of text and has obviously taken some time to write.

Check if I or another agent has already saved the prompt. Use date and topic name as the filename: like "Prompts/07_11_2026_PROMPT_LOGGING.md". Rename the file if I have already saved it as I will probably forget the naming conventions.

Make clear instructions for agents to do this.

Demonstrate your ability by starting with this prompt.
