## What this document is

This is the rulebook for the NoöPunk restart. It exists so that every rule has one obvious home and
one obvious history: a rule is written here **first**, and the Godot game implements that same rule.

It is deliberately blank. There are no attribute tables, no skill list, no combat procedure, no
psionics, no hacking rules, no factions and no scenario content — not because they are forgotten, but
because they will be authored one piece at a time.

## How this rulebook grows

1. Tomi writes one rule, scenario fragment or interaction.
2. It is written into this document, in the section it belongs to.
3. The same decision is implemented in `noopunk2/` (the Godot project) so it can be played.
4. The two are checked against each other and merged together.

Nothing is added here on the assumption that a complete OSR/CWN/SWN system must exist first. If a
section is empty, that is the current state of the design, not an oversight.

## Premise
