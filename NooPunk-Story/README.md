# NoöPunk Story — the author's track

> **Owner: Tomi.** This subproject exists so that the story can be written before it is adapted.
> Nothing here is generated by an agent unless it lives under `Graph/`.

## What is here

| Path | Who writes it | What it is |
| --- | --- | --- |
| `Story/` | **Tomi only.** Agents may read, and must never write, edit, move, reformat or delete. | The branching script, dialogue, scenes, paths and novel chapters. The source of truth. |
| `Graph/` | Agents, within the contract | The Story Graph adaptation: series → episode → scene, choices, prerequisites, consequences. A **derivative**, never a replacement. |
| `Graph/templates/` | Agents | Empty author-facing templates for a new branching scene and a new chapter. |
| `Graph/examples/` | Agents | Synthetic examples that demonstrate the conversion contract. Never Tomi's prose. |

## Direction of information

```
Tomi's Story/  ──read──▶  Graph/  ──consume──▶  NooPunk-RPG
```

The arrow never points backwards. If a graph needs a fact the manuscript does not give, the answer is a
**review note**, not an invented line of canon.

## The one rule that matters

`Story/` is human-authored. An agent that needs a change there writes a proposal **outside** the directory —
in the graph as a note, in an issue, or in a review comment — and waits. This is enforced by
`tools/check_story_boundary.py`, which fails when a change under `Story/` happens without an explicit
human authorisation in the environment.

See [`AGENTS.md`](AGENTS.md) for the operational form of that rule.
