# Story — authoring policy

> **This directory is Tomi's manuscript.** The policy lives here, in an ordinary file, because the repository
> blocks agents from editing `AGENTS.md` without explicit human approval — which is the same rule this page
> describes, applied one level up.

## Who writes here

**Tomi only.** A human author, writing a branching script, dialogue, scenes, paths, or the novel chapters the
script may become.

## What an agent may do

- read any file here;
- quote a short passage in a review note or an issue;
- index the files (path, title, scene count) in `Graph/`;
- ask a question about anything ambiguous.

## What an agent may not do

- create, edit, reword, reformat, rename, move or delete anything here;
- add a placeholder, a sample, a template or a "temporary" file;
- correct a typo, harmonise punctuation, or normalise headings;
- copy a draft out, edit the copy, and present it as the original.

## What to do instead

Write the observation where it belongs:

1. **A graph gap** — note it in `../Graph/` with the passage it came from and the decision needed.
2. **A question about the story** — open a comment on the relevant issue, addressed to Tomi.
3. **Something that looks like an error** — say so; do not fix it. The manuscript is allowed to be wrong.

## Why the rule is absolute

An agent that "improves" a draft destroys the only copy of an author's voice, and the damage is invisible in a
diff. The graph is a derivative and can be regenerated; the manuscript cannot.
