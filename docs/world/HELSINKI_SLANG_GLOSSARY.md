# Helsinki slang and NoöPunk glossary — pointer

The canonical vocabulary reference is the repository-root [`GLOSSARY.md`](../../GLOSSARY.md).
Its entries and provenance were migrated there, and this file must not maintain a second list.

Why one file: the Markdown glossary is authoritative; the player `dictionary` command and any future
JSON index are generated from or parity-checked against it. A second hand-curated glossary would drift.

See also: [`docs/FINNISH.md`](../FINNISH.md) for the language policy.
