# Lakkahaltia playtest protocol (#708)

**Status: protocol, not results.** No tabletop session has been run. This document exists so
that when one is, it produces evidence rather than impressions — and so that the difference
between "we played it" and "it worked" is visible.

**An agent cannot complete this issue.** Tabletop play needs a human referee and human
players; the acceptance criteria ask for *recorded sessions*. What follows is the instrument.

---

## 1. What is being compared

| arm | rule |
|---|---|
| **Current** | a clue is obtained by a CWN check against a difficulty |
| **Proposed** | a competent character obtains the clue without a roll; access and declared inquiry still gate it |

Same case, same players, both arms where practical.

## 2. What to log, per scene

| field | why |
|---|---|
| **stalls** | did the table stop because nobody could find the exit? This is the failure GUMSHOE exists to prevent |
| **retries** | how many attempts at the same clue, and what each cost |
| **spotlight** | which character acted, and whether one competence dominated |
| **resource cost** | time, credits, favours, injuries — itemised, not summarised |
| **hypothesis changes** | when a player changed their theory, and what changed it |
| **non-PSI routes** | whether an ordinary explanation remained reachable at every point |

## 3. The six stress cases (E1–E6)

1. **Patient refusal** — the witness will not talk. The clue must remain obtainable another way.
2. **Unavailable specialist** — nobody has the competency. Does the case die, or is there an alternative method?
3. **Offline terminal** — the access exists, the machine does not. Time becomes the cost.
4. **Lost original** — the record is gone; what survives, and is it enough?
5. **Wrong hypothesis** — the table commits to the mundane reading and is wrong. **The game must not correct them.**
6. **Fixed truths** — the case has one mundane, one anomalous and one deceptive reading, fixed in advance. The referee must not move them to reward a theory.

## 4. Decision log to fill

For each of D704-1 … D704-5, record **accept / revise / reject** with the author's reason in one
sentence. A decision without a reason is not usable later.

## 5. Overlay evaluation

Test motivation/tag/consequence/clock overlays and confirm each one **changes no fact, no
combat number and no resource cost**. An overlay that silently moves a difficulty is not an
overlay; it is a rule change wearing a costume.

## 6. Boundaries to record

- no free powers from a competence
- no spending of a rank to obtain a core clue
- no generic System Strain as the price of a favour
- SWN/BCI/embodiment limits, stated explicitly

## 7. Why this is a protocol and not a completion

The issue's acceptance criteria are **recorded human sessions**. Producing them requires a
table; producing a form for them is what can be done without one. Closing #708 without
sessions would mean asserting evidence that does not exist.
