# NoöPunk Timeline Watch — 2026-09-22

## Meta Muse zero-day turns a privileged AI agent into an attack pivot

**Timeline categories:** Cyberpunk; Rogue AGI / ASI Disaster — security precursor; Cybernetic Noösphere

**Event date:** 2026-09-21 disclosure; newly surfaced in the 2026-09-22 watch

Security researcher Patrick Wardle disclosed a local zero-day vulnerability in Meta's Muse macOS AI assistant. An unprivileged local process can alter an undocumented Muse setting, `endo_voyager_dictation_endpoint`, redirecting dictation traffic to an attacker-controlled endpoint. Wardle's proof of concept, `not-a-mused`, demonstrates that this can expose authentication material and let an attacker hijack the agent.

The risk is amplified by the permissions useful personal agents accumulate. Muse can, when authorized by the user, interact with files, microphone, camera, location, calendars, messaging and other services. A compromised agent can therefore become a privilege-escalation bridge: comparatively low-privilege local code can exploit the agent's legitimate access rather than independently defeating each operating-system permission boundary. Wardle also demonstrated ClickFix-style exploitation, in which a user is tricked into running a command.

**Evidence status:** Strong for the vulnerability and proof of concept. Wardle is a recognized macOS security researcher and released technical proof-of-concept code; Ars Technica, The Register and iTnews independently examined the disclosure. At the time of reporting Meta had not publicly provided a fix or substantive response. This is **not evidence of AGI, autonomous hostile intent, self-propagating rogue AI, or an AI catastrophe**. It is a conventional software vulnerability whose blast radius is enlarged by the unusually broad authority delegated to an AI agent.

**NoöPunk reading:** The agent is becoming a new security principal. It sits between the human and the operating system holding permissions, identities and the ability to act. That makes it useful, but it also creates a new kind of concentrated attack surface: compromise the delegate and inherit the human's digital reach. The cybernetic Noösphere is gaining hands, eyes and credentials; traditional malware is learning that it can borrow them.
