## What the numbers mean

- **Tabletop:** the baseline covers **47** surfaces exactly and **15** at category level; it is a source-dependent baseline, so the CWN book/SRD is still required at the table. This is the intended, licensed arrangement.
- **Reader rulebook:** **15** surfaces still have a chapter that teaches a superseded mechanic, **17** have related material only, and **30** are absent. The banner at the top of RULEBOOK.md is correct, but the chapters below it are not rewritten. That is the largest documentation gap in this audit.
- **Python:** **42** surfaces have a module and a test, **16** have code without a test that names the rule, and **4** are missing. `implemented` is not the same claim as `verified against the book`.

## Source limitations

- The hosted SRD omits **Antagonists/NPC statistics**; the free rulebook may contain it, but no page-cited transcription exists in this repository. It is not claimed as covered.
- Deluxe-only material (some cyberware, vehicle and hacking options) is out of scope until a licence review and legally available text exist. Do not fill these from memory.
- SWN/AWN are licence-constrained in this repository; their rows are not part of this CWN count.

## No CWN rule was changed

This audit adds data and a report. It does not edit `src/rules/`, `mud/nopunk_mud/`, the CWN SRD tables, or any published procedure. The only rulebook edit in this change is the authority statement at the top of `RULEBOOK.md`, which now names CWN as the mechanical core and marks the conflicting chapters historical — a statement of the existing baseline decision, not a new rule.

## Maintenance workflow (same-PR gate)

Per AGENTS.md, prose is not a CI test target, so the correspondence is enforced by a review checklist rather than a text matcher:

1. A rule or mod change updates its **CWN source reference**, **tabletop procedure**, **Python module**, **test**, and **this audit row** in the same pull request.
2. A new or changed Python rule that cannot name a tabletop reference is not finished.
3. A rulebook chapter that conflicts with the baseline is either rewritten or marked historical; it may not stay silently authoritative.
4. `python3 tools/cwn_1068_coverage.py --check` must pass (ids and code paths only).
5. `python3 tools/check_cwn_compliance.py` and the engine-boundary check run in CI as before.
