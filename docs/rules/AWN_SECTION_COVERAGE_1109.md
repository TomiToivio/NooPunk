## Status definitions

- **verified** — an AWN procedure implemented in src/rules with tests that pin the printed numbers
- **verified_reuse** — the identical procedure already exists for CWN; one resolver is shared and a test proves the AWN numbers
- **partial** — some of the section is implemented and the remainder is named
- **documented** — a tabletop procedure exists and is cited; the source asks for a procedure, not code
- **unverified** — an equivalent CWN procedure exists but equivalence to the AWN numbers has not been proven
- **missing** — no implementation; the gap is recorded so it cannot be mistaken for coverage
- **not_applicable** — setting text, an example, guidance, or content excluded by an explicit decision

## What this report does not claim

* It does not claim AWN's text is reproduced. AWN has no verified open-text licence, so the register
  records page numbers and independently written procedures, never the book's prose or tables.
* It does not reproduce book text, tables or page images. The PDF is the author's authorised copy, is not in the repository, and is not redistributable.
* A `verified_reuse` row means one resolver serves both games **and a test pins the WWN numbers**. Where that test does not exist, the row says `unverified` — see saving throws.
