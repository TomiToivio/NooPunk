## Status definitions

- **verified** — an SWN procedure implemented in src/rules with tests that pin the printed numbers
- **verified_reuse** — the identical procedure already exists for CWN; one resolver is shared and a test proves the SWN numbers
- **partial** — some of the section is implemented and the remainder is named
- **missing** — no implementation; the gap is recorded so it cannot be mistaken for coverage
- **unverified** — an equivalent CWN procedure exists but equivalence to the SWN numbers has not been proven
- **not_applicable** — setting text, an example, guidance, or a subsystem excluded by an explicit design decision

## What this report does not claim

* It does not claim SWN's power text is reproduced. SWN has no verified SRD licence, so the register
  records page numbers and NoöPunk-authored technique ids, never the book's ability text.
* It does not reproduce book text, tables or page images. The PDF is the author's authorised copy, is not in the repository, and is not redistributable.
* A `verified_reuse` row means one resolver serves both games **and a test pins the WWN numbers**. Where that test does not exist, the row says `unverified` — see saving throws.
