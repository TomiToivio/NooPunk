# Eclipse Phase 2E homebrew licensing and attribution

The experimental rules code under `src/eclipse_phase_homebrew/` and the Concordia
adapter `src/concordia_runtime/ep2_adapter.py` are part of the NoöPunk Eclipse
Phase 2E homebrew prototype tracked in issue #60.

**Eclipse Phase** is created by **Posthuman Studios**.

Creative Commons terms and attribution guidance:
https://eclipsephase.com/cclicense/

The current prototype should be treated as **CC BY-NC-SA-derived material** where
it adapts Eclipse Phase rules expression. EP-derived portions require attribution,
are noncommercial, and derivatives must use compatible ShareAlike terms.

NoöPunk-original setting material is separate from Eclipse Phase-derived material
unless a file explicitly says otherwise.

This repository does not bundle the Eclipse Phase 2E rulebook PDF. Public reference
sources are recorded in `docs/sources/EP2_HOME_BREW_SOURCES.md`.

NoöPunk is an unofficial fan/homebrew project and is not affiliated with or
endorsed by Posthuman Studios.
