# Example: Act I procurement case (authored records)

Four record types in the shape proposed by
[`docs/design/DRAFT_GRAPH_SCENES_1164.md`](../../../design/DRAFT_GRAPH_SCENES_1164.md):

| file | record |
|---|---|
| [`series_campaign01.md`](series_campaign01.md) | series |
| [`ep01_the_tuesday_complaint.md`](ep01_the_tuesday_complaint.md) | episode |
| [`sc01_04_interview.md`](sc01_04_interview.md) | scene |
| [`domain_helsinki.md`](domain_helsinki.md) | physical graph domain (nodes and edges) |

They are **examples of the authoring format**, not game content, and nothing loads them. The scene demonstrates the
one invariant that matters most: the two **core** clues are granted for competence plus declared access and
inquiry, so a bad roll can cost time, trust and money — never the case.
