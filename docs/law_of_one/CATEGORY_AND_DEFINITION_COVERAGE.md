# Law of One RPG — category and definition coverage (#1124, Phase 1 appendix)

> Companion to [`RULES_INVENTORY.md`](RULES_INVENTORY.md) and [`COVERAGE_MAP.md`](COVERAGE_MAP.md).
> This appendix closes the two source indexes the issue names explicitly: **all 39 top-level
> categories** and **all 20 definition subcategories**. It maps each to an inventory disposition;
> it does not add a second set of rules.

Source indexes: <https://www.lawofone.info/categories.php>,
<https://www.lawofone.info/c/Definitions>. Where a category is setting/reference material rather
than a rule, that is stated; “out of scope” is a disposition, not an omission.

## What this appendix does not do

It does not turn a category into a mechanic, a historical person into a species, or a glossary
term into a stat. It exists so a reviewer can see that **nothing was silently dropped** when the
inventory chose its 50 rows.
