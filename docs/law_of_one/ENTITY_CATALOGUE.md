# Law of One RPG — entity and civilisation catalogue (Phase 1)

> **Research reference, not canon and not a player-options list.** #1124 asks for a separate, source-cited
> inventory of the named beings, civilisations and groupings in the material — with the explicit warning that
> **species, faction, density, dimension and place/time of origin are different properties** and must not be
> collapsed into one another.

**This catalogue is deliberately incomplete.** It carries a schema and the entries this pass could cite. The full
enumeration needs session-level reading, and inventing names to fill a table would corrupt the one thing this
document is for. §4 says exactly what is missing.

## 1. Fields

| Field | Meaning |
|---|---|
| `name` | As the source names it, original spelling preserved |
| `type` | `species` · `civilisation` · `SMC` · `entity` · `role` · `construct` · `uncertain` |
| `origin` | Reported origin (planet, system, "elsewhere") — **not** a density |
| `density` | If the source gives one; leave blank otherwise |
| `realm` | Space/time vs time/space, if specified |
| `affiliation` | Confederation, Orion, unaligned — if given |
| `certainty` | `attested` · `ambiguous` · `disputed in source` |
| `play relevance` | What a fourth-density Earth game might do with it — or "reference only" |

**Rule:** a being having a density is not the same as being *from* a density. A Wanderer is a being of one
density incarnated in another; that is precisely the distinction this schema exists to keep.

## 3. What the schema deliberately refuses

- **Species ≠ faction.** Wanderers are a role, not a species. The Orion group is a polarity alignment, not a
  biology. The Confederation is a grouping, not a government with a fleet list.
- **Density ≠ dimension ≠ realm.** Time/space is a realm, not a place on a map; density is an evolutionary stage,
  not a parallel dimension.
- **Origin ≠ affiliation.** A Venus-origin entity and an Orion-aligned entity are different facts about a being.
- **No playable races.** #1124 is explicit: **PCs remain StO fourth-density humans.** Nothing in this catalogue
  becomes a character option.

## 4. Stated gaps

1. **Not enumerated:** the full set of named species, planetary civilisations and SMCs requires reading the
   `People` (27 sub-entries) and `Cosmology`/`Earth History` categories session by session. This pass did not.
2. **No invented names.** Nothing has been added from wider UFO lore or from NoöPunk canon; only source-attested
   entries appear above.
3. **"Men in Black" is marked ambiguous** because the repository's own research sheet records a sibling claim
   about 12.21 that was corrected. It is listed to keep the ambiguity visible, not to canonise a species.
4. **Earth-origin entities** beyond the future fourth-density inhabitants are not catalogued in this pass.
