# Document register — one canonical document per subject

Every subject below has had more than one document written about it by more than one agent, usually on the
same day. This file says which one is authoritative. Anything listed as *superseded* carries a
`> **Superseded:**` banner at the top of the file, still builds, and is kept only as history.

**If a subject is not in this table**, check `grep -rln "<subject>" docs/` before writing a new document —
and if you find two answers to the same question, merge them and add the row here instead of adding a
third. The protocol that goes with this register is [design/AGENT_COORDINATION.md](design/AGENT_COORDINATION.md).
