# Conscious Agent Network

Noöpunkin Conscious Agent Network on oma spekulatiivinen synteesi Donald
Hoffmanin Conscious Realism / conscious-agent-formalismista ja Giacomo Mauro
D'Arianon sekä Federico Fagginin Quantum Information Panpsychism -mallista.
Keskeisiä rinnakkaislähteitä ovat Bernardo Kastrupin analyyttinen idealismi
(yhteinen tietoisuuspohja ja dissosiaatio) sekä Penrose-Hameroffin Orch OR
(biologisen kvanttikytkennän kiistanalainen mekanismihypoteesi).
Se ei ole Hoffmanin ja Fagginin yhdessä julkaisema teoria.
