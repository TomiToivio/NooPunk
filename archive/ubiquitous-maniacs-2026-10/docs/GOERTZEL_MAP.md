# Goertzel -> Noöpunk: käsitteellinen riippuvuuskartta

## Kartan lukusääntö

Nuoli tarkoittaa historiallista, arkkitehtonista tai Noöpunkin ehdottamaa
rakennussuhdetta - ei todistusta eikä teorioiden identiteettiä. `[A]`, `[B]` ja
`[C]` vastaavat akateemista, spekulatiivista ja fiktiivistä tasoa.

## Kognitiivinen linja

```text
complex systems [A]
    -> computational patternism [A/B]
    -> PsyNet / dual network [B]
    -> artificial selfhood + subselves [A/B]
    -> shared knowledge substrate [A]
    -> cognitive synergy [A]
    -> OpenCogPrime / Atomspace [A]
    -> typed metagraph + chronomorphisms [A]
    -> Hyperon / MeTTa / reflective rewriting [A]
    -> UFAB Ragnarök cognitive architecture [C]
```

Ratkaiseva katkos on PsyNetin ja ontisen tietoisuuden välillä: PsyNet mallintaa
kognition pattern-dynamiikkaa, ei ensimmäisen persoonan qualian syntyä.

## Kvantti- ja PSI-linja

```text

    + algebraic consciousness [B]
    -> evolutionary quantum computation [B]
    -> quantum/panpsychic cognition hypothesis [B]
    -> glocal mind + morphic/eurycosmic routes [B]
    -> Occamistic / multiscale resonance [B]
```

Vuoden 2025 *Patterns of Quantum Cognition I* kytkeytyy varmuudella
chronomorphism-linjaan julkaisutietojensa perusteella. Sen suhdetta fyysiseen
kvanttilaskentaan tai tietoisuuteen ei päätetä ennen kokotekstin analyysiä.

## Global brain -linja

```text
Internet + intelligent agents [A]
    -> distributed Web cognition [A/B]
    -> World Wide Brain [B]
    -> human-AI mindplex [B]
    -> technological + experiential singularity [B]
    -> Noöpunk noösphere [C]
    -> PSI-enhanced planetary coupling [C]
```

Goertzel tarjoaa cyberneettisen ja AGI-arkkitehtonisen sillan. Teilhard,
McLuhan ja Castells tuovat eri historialliset, media- ja valtateoreettiset osat;
PSI-takaisinkytkentä on Noöpunkin oma fiktiivinen lisäys.

## Epävarmuus- ja tutkimuslinja

```text
probabilistic inference [A]
    -> PLN strength + confidence [A]
```

Viimeinen nuoli ei tarkoita, että `Both` olisi qubit. Looginen ristiriita,
episteeminen epävarmuus ja fysikaalinen superpositio säilyvät eri käsitteinä.

## Leikkauspiste: yksi multiplex-metagraafi, monta näkymää

```text
                 Cognitive view
            memory / belief / goal / self
                       |
Physical view ---- typed metagraph ---- Cyber view
 body / place          |               device / protocol
                       |
                  Social view
             trust / role / institution
                       |
                 Noetic proxy [C]
          corridor / attractor / provenance
```

Metagraafi on yhteinen **representaatio- ja tapahtumakerros**, ei väite siitä,
että kaikki näkymät olisivat ontologisesti sama asia. Physical, Cyber ja Social
ovat klassisesti simuloitavia. Cognitive on osittain episteeminen malli.
Noetic on fiktiivinen/filosofinen proxy eikä qualian täydellinen telemetria.
