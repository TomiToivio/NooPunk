# `ubiquitous-maniacs-2026-10` — the *Ubiquitous Maniacs* corpus, imported

This directory holds the **NoöPunk *Ubiquitous Maniacs* corpus**, imported from a **different
repository** on 2026-10-22. It is a **source-of-record**: the material is preserved with
content hashes so its retrievability is provable rather than claimed.

**Nothing here is canon.** The corpus predates the current rulebook, is written mostly in
Finnish, and several of its premises **contradict** this repository's canon. Those conflicts are
recorded in [`MIGRATION_MAP.md`](MIGRATION_MAP.md) and are **not** resolved here — resolving them
is the author's decision (`AGENTS.md` §1).

- **[`MANIFEST.md`](MANIFEST.md)** — every imported file with its byte size, its sha256, the
  upstream git blob sha and the upstream commit that last touched it; plus the files excluded
  from the import and why, the material that was never upstream, and the third-party material
  that was retained.
- **[`MIGRATION_MAP.md`](MIGRATION_MAP.md)** — where each unit lands, the twelve concrete
  conflicts with the current canon, what was not imported and why, the licence status, and the
  six questions this import leaves for the author.
- **[`manifest.json`](manifest.json)** — the machine-readable inventory, generated by
  `tools/build_ubiquitous_maniacs_manifest.py`.

## Verification

```sh
python3 tools/build_ubiquitous_maniacs_manifest.py --check   # the manifest matches the tree
python3 tools/release_packaging_guard.py --mode audit         # the import changes no release class
```

The manifest is **generated, not hand-written**: it recomputes every sha256 and re-derives every
upstream blob sha and commit from the source repository, so a drift between the archive and its
manifest is a **failing check** rather than a silent inconsistency.

## Two things a reader should know before using anything in here

1. **The corpus's own data is missing.** `data/lab_people.csv` and `data/lab_relationships.csv`
   were **never committed upstream**, so the imported `app.py` and `social_demo.py` cannot run as
   shipped. The `src/` library itself does not depend on them. Nothing was invented to fill the
   gap.

2. **The corpus's `tests/` are not this repository's tests.** They exercise the imported `src/`,
   not the live `strategy_game/`, and are not part of this repository's test run.
