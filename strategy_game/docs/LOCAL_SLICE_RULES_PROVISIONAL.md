# Experimental local turn contract (#322, #323, #324)

These rules are **unapproved playtest assumptions** in `local_slice.py`, not revisions to `strategy_game/RULEBOOK.md`. Each faction has exactly four named leader slots, each with one portfolio and at most one active mission per turn. `rest` consumes that slot. No leaderless actions; routine member activity is abstracted as resources. A leader on unavailable status cannot act or supply passive bonuses. Reassigning portfolios is explicit.

Turns represent abstract political intervals. A global shock alters local legitimacy, then each available leader grants at most one capped portfolio benefit (politics +1 legitimacy, networks +1 reach, operations +1 treasury, research +1 on local tech adoption). Players assign campaign/organize/negotiate/local technology adoption/investigate/rest missions. Each mission targets a city location and optional character; travel beyond directly linked locations is invalid. Seeded d6 plus skill, selected bounded bonuses, location pressure and travel cost decides outcome. Support is stored **per location and per faction**, not a universal hegemony score. Claims remain descriptive and rival meanings persist.

The two sparse personal relationships provide a trust modifier in negotiation and a single deterministic 'share evidence' trust change on a scheduled turn. This is a prototype event choice, not an interactive event deck. All three factions follow the same mission limit. Leaders use placeholders pending sourced canon reconciliation. The CLI prints JSON logs/state. To experiment: `python -m strategy_game.local_slice --turns 12 --seed 2027`. No LLM, game server or global simulation.

**Known omissions before complete closure:** actual player-selected character-event choices; richer rival AI rather than identical scripted orders; organizational form transitions; evidence/claim disputes affecting political support; UI scenario picker; backfilled canonical Ukweli NPCs and complete historical lore audit; formal scenario schema validator; local map win/loss conditions. These are not silently represented as finished.
