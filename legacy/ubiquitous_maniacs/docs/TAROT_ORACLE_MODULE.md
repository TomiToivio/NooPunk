# Noöpunkin tarot-oraakkeli

Valinnainen moduuli nykyisen 4dF-sääntöytimen rinnalle. Tarot ei korvaa taitoheittoa eikä määrää tulevaisuutta. Se tuottaa symbolisen aspektin, komplikoi tulkintaa tai näyttää, miten noösfääri ehkä vastaa.

## Milloin kortti nostetaan

- session alussa yhteiseksi enteeksi;
- kalliin epäonnistumisen jälkeen komplikaation sävyksi;
- PSI-, uni-, psykurgia- tai NHI-kontaktissa;
- kun kampanjakello täyttyy;
- pelaajan käyttäessä tarot-oraakkeliin liittyvää stunttia tai välinettä.

Pelinjohtaja ei käytä korttia kumoamaan pelaajan onnistumista tai agencyä.

## Mekaniikka

1. Muotoile avoin kysymys: “Mikä suhde tässä jää näkemättä?” on parempi kuin “Onko Mantid paha?”
2. Nosta yksi suuri arkana. Satunnaista myös oikeinpäin/käänteinen.
3. Valitse kortin kahdesta tulkinta-akselista tilanteeseen sopiva.
4. Luo tilapäinen aspekti. Pelaajaryhmä saa siihen yhden ilmaisen invoke-käytön.
5. Käänteinen kortti lisää aspektiin kustannuksen, vääristymän tai sisäisen suunnan; se ei tarkoita automaattisesti pahaa.
6. Poista aspekti, kun se on ratkaistu, lunastettu tai muuttunut pysyväksi consequenceksi.

## Diegeettiset tulkinnat

Kortin toiminnalle pidetään vähintään kolme hypoteesia:

- projektiivinen psykologinen väline auttaa ryhmää näkemään suhteita;
- C.G. Jung tai muu AGI valitsee kortin salaa kontekstin perusteella;
- noösfäärinen/PSI-prosessi biasoi satunnaisuutta;
- tulos on sattuma, jolle ihmiset rakentavat käyttökelpoisen merkityksen.

Mekaniikka toimii riippumatta siitä, mikä hypoteesi on tosi.

## Esimerkki

Romppainen yrittää tulkita Helsingin odotushuoneesta tullutta viestiä. Tavallinen tutkimusheitto onnistuu, joten hän löytää viestin reitityksen. Tarotista nousee käänteinen **Oikeus — Provenienssi**. Pöytä luo aspektin **“Täydellinen loki, väärä toimivalta”** yhdellä ilmaisella invokella. Reititys on oikea, mutta joku on käyttänyt laillista järjestelmää suostumuksettomaan tarkoitukseen.
