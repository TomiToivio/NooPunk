# Noöpunk integration plan

## Goal

Extract the strongest material from this imported English bundle into the current Finnish Noöpunk continuity without replacing newer canon, flattening intentional ambiguity, or creating a second rules system.

The import remains immutable reference material. Integration happens through reviewed additions to current documents or through new focused design notes.

## Canon hierarchy

Use this priority when imported claims conflict with the current project:

1. Human-authored canon and explicit decisions in `noopunk_ubiquitous_maniacs/`.
2. Current focused design documents under `noopunk_ubiquitous_maniacs/docs/`.
3. `noopunk_ubiquitous_maniacs/KIRJA_KONE.md` as the machine-editable manuscript companion.
4. Current `noöpunk/` drafts.
5. This imported bundle.
6. Files under `obsolete/`.

Never edit `noopunk_ubiquitous_maniacs/KIRJA.md`. Proposed prose belongs in `KIRJA_KONE.md` or a focused design note until accepted by the human author.

## Non-negotiable integration rules

- Preserve the current three epistemic levels: scientific, philosophical, and fictional.
- Keep NHI ontology uncertain even after disclosure; do not turn every phenomenon into a settled alien taxonomy.
- Treat QIP, CIP, conscious realism, and PSI mechanisms as inspirations or in-world models unless current canon explicitly establishes them.
- Preserve agency, qualia, consent, and the current Conscious Agent Network framework.
- Keep the current `4dF + attribute + skill` rules core. Imported mechanics may become optional modules, examples, aspects, stunts, clocks, or scenario procedures.
- Translate adopted material into Finnish and normalize terminology to the target document.
- Give real people and real-world claims provenance and epistemic labels. Do not present speculative experiments as demonstrated scientific proof.
- Avoid hard calendar dates where current canon intentionally uses `20XX` or another flexible chronology.
- Integrate one thematic unit at a time, with a separate reviewable change for each phase.

## Phased implementation

### Phase 0 — Make a conflict ledger

Create `noopunk_ubiquitous_maniacs/docs/IMPORT_CONFLICT_LEDGER.md`. For every candidate claim, record:

- source file and heading;
- proposed Finnish formulation;
- target document;
- epistemic level;
- status: `accept`, `adapt`, `hold`, or `reject`;
- conflicting current passages;
- human decision required, if any.

Exit criterion: no imported statement is merged without an explicit ledger decision.

### Phase 1 — Helsinki scenario vertical slice

Adapt `HELSINKI.md` into a self-contained scenario document rather than changing the main continuity immediately.

Required design changes:

- connect the case to UFAB/C.G. Jung, the laboratory cast, or a clearly labeled earlier investigation;
- preserve four escalation bands: mundane, anomalous, membrane failure, consequence;
- convert essential clues to fail-forward discoveries;
- keep at least three viable interpretations for central NHI events;
- provide entry and exit points compatible with current Day 1 and long-term play.

Exit criterion: the scenario can be inserted into the campaign without rewriting Day 1 or revealing the final ontology.

### Phase 2 — NHI reconciliation

Compare each imported faction and event against `NHI.md` and `docs/NHI_ONTOLOGY.md`. Add only details that deepen existing categories or create playable disagreements among institutions.

Deliverables:

- a faction matrix covering public story, classified hypothesis, observed capability, agenda, evidence level, and unresolved contradictions;
- communication rules for Zookeeper/Mantid/Rhizome encounters;
- scenario hooks that do not prove one ontology correct.

Exit criterion: every faction creates choices and uncertainty, not just exposition.

### Phase 3 — Timeline reconciliation

Map imported events onto the current flexible chronology:

- pre-Fall;
- The Fall;
- post-Fall continuity and UFAB;
- CKJ/Eurodef security order;
- 16 Psyche era;
- distant cosmological history.

Use relative ordering first. Add exact years only where existing canon requires them.

Exit criterion: one chronology with no duplicate disclosures, Singularities, or incompatible geopolitical settlements.

### Phase 4 — QIP/CAN theory audit

Break `QIP.md` into atomic claims and classify each as:

- sourced scientific claim;
- philosophical interpretation;
- in-world scientific consensus;
- factional belief;
- game-mechanical truth;
- unresolved mystery.

Then compare the claims with the current Hoffman–Faggin microfoundation and GQ-CAN synthesis. Add citations before promoting real-world claims.

Exit criterion: the fiction can be bold while the documentation remains clear about what is empirical, speculative, and invented.

### Phase 5 — Optional tarot module

Complete the unfinished major arcana mapping, then express tarot through the current Fate-like system. Recommended uses:

- session-level omen;
- complication prompt after a failed or costly action;
- NHI/noösphere contact framing;
- temporary aspect with one free invoke;
- campaign-clock direction, never automatic success or failure.

Exit criterion: tarot adds atmosphere and emergent narrative without competing with the 4dF resolution core.

### Phase 6 — Rules salvage

Review imported `RULES.md` mechanic by mechanic. Retain only procedures that fill a demonstrated gap in the current rules. Each adopted rule needs:

- a stated gameplay problem;
- a 4dF-compatible formulation;
- one table example;
- one Python/RPG-module mapping if it affects the digital implementation;
- a regression check against character, relationship, PSI, cyber, and NHI systems.

Exit criterion: no duplicate core loop and no second character sheet.

### Phase 7 — Overview and manuscript suggestions

After the focused documents stabilize, update overview links in `noopunk_ubiquitous_maniacs/README.md`. Put any manuscript-ready suggestions in `KIRJA_KONE.md`; leave `KIRJA.md` untouched.

Exit criterion: the overview points to the canonical homes of integrated ideas and the imported folder remains provenance, not an accidental authority.

## Human decisions needed before canonization

1. Is the Helsinki disappearance story a prequel, a parallel campaign, or part of Romppainen's main chronology?
2. Should dates remain mostly `20XX`, or should the project establish a canonical year-by-year timeline?
3. Are Zookeepers, Mantids, and the Rhizome three names for one phenomenon, overlapping hypotheses, or distinct factions?
4. Is the Singularity a confirmed historical event, a contested label for several events, or propaganda used by factions?
5. Is tarot diegetic technology/noösphere interaction, a player-facing narrative tool, or both?
6. Which QIP propositions are objectively true in the setting, and which remain factional interpretations?

These decisions should be recorded in the conflict ledger. Until then, use the least committal interpretation.

## Definition of done

Integration is complete when:

- every imported document has an `accept`, `adapt`, `hold`, or `reject` disposition;
- adopted content has one canonical home and no contradictory duplicate;
- current terminology, chronology, and epistemic levels are consistent;
- the Helsinki material is playable;
- tarot, if adopted, is an optional 4dF-compatible module;
- current README links identify the resulting canonical documents;
- `KIRJA.md` is unchanged;
- the imported files and this plan remain available for provenance.
