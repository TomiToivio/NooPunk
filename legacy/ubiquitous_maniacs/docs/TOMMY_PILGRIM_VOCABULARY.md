# TOMMY PILGRIM'S VOCABULARY — The 1974 Precognitive Renderer

This is the translation table between 2026 concepts and Tommy Pilgrim's 1974
vocabulary. Use it when writing Noöpunk fiction, UI text, scenario content,
and character dialogue. The 1974 terms are diegetic — they exist inside the
world because Tommy Pilgrim rendered 20XX through a 1974 brain.

## Usage rules

1. **Always use Tommy's terms in fiction and dialogue.** A character says
   "the Oracle Computer," not "the AGI." The UI shows "Computerized Social
   Karma," not "Recommender Score."

2. **Use real terms in simulation code and academic documentation.** The
   code uses `llm_agent`, `discourse_graph`, `hegemony_index`. The fiction
   uses Tommy's translations. The gap between them IS the aesthetic.

3. **The gap is diegetic.** When a 2026 researcher reads Noöpunk and writes
   a paper mapping "computerized social karma" to recommender systems, that
   IS the Noöpunk experience. The game does the same thing: it shows you
   Tommy's 1974 rendering, then reveals the 2026 formalization underneath.

4. **Tommy's terms are warm; the real terms are cold.** "The Dreaming
   Machines" is warm. "Data center" is cold. The contrast IS Noöpunk.
